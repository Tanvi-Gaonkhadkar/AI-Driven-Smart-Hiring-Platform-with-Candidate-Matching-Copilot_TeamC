# AI-Driven Smart Hiring with Candidate Matching Copilot

An AI-powered recruitment platform that helps recruiters streamline candidate screening, matching, interview planning, AI interviews, evaluation, and hiring decisions.

## Key Features
- 📄 Resume Analysis
- 🔍 AI Candidate Screening & Matching
- 🎤 Interview Copilot
- 🤖 AI-Powered Interviews & Answer Evaluation
- 📊 Hiring Analytics
- 👥 Talent Management & Onboarding

## Tech Stack
- **Frontend:** Streamlit
- **Backend:** Python
- **AI:** Ollama + Llama 3.2
- **Database:** SQLite
- **Data Processing:** Pandas

## Setup

```bash
git clone <repository-url>
cd ARTM_CopilotDashboard
